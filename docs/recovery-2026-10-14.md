## Что нужно для действующего сайта

Финальная production-сборка (`npm run build`) прошла. При запуске через `npm run start` проверены HTTP 200 для health, поиска ортопеда с датой 13.10.2026 и 7 результатов расписания колоноскопии; административный sync и cron без ключа вернули ожидаемый HTTP 401.

Изменения необходимо доставить в проект Vercel. Публикация облачной среды Codex сама по себе не обновляет сайт. После деплоя проверить commitSha в `/api/health`, результат поиска и авторизованные `/api/sync/last` и `/api/sync`. Проверка поиском должна автоматически обновить старый снимок; ручной sync требует существующего административного ключа. Секретные значения нельзя передавать в чат.

В черновик сетевых настроек среды добавлен `ima-li-termina.vercel.app` для диагностики публичного сайта; ранее сохранённые `www.kccg.me` и `r.jina.ai` сохранены. Позднее фактический HTTP 200 подтвердил доступ к публичному health. Это не доказательство деплоя исправления.

Пользователь уточнил, что ошибок входа не видит: прекращается обновление данных. Это не подтверждает истечение сессии Vercel. Публичный health показывает наличие административного и cron-ключа, но значения и фактическая история cron недоступны. Запрос `/api/sync/last` без административного ключа возвращает ожидаемый 401. На проверенном адресе отчёт сейчас уже 12.10.2026, поэтому нельзя утверждать, что он всё ещё стоит на 14.08.2026; это была исходная информация пользователя.
